# liberty: the SS Jeremiah O'Brien at Pier 35

The SS Jeremiah O'Brien, a WWII Liberty ship berthed at Pier 35 in San Francisco, as a night concert stage, built
entirely in code (three.js / WebGL2) and explored in the browser:
- the bay, the waterfront, the bridges and the city;
- the pier and the ship herself;
- pelicans, gulls and the bay's water;
- the hour from blue hour to night;
- a show of stage lights, lasers, pyro and the ship's own guns;
- a two-and-a-half-minute tour reel.

**Open it:** https://bishpls.github.io/liberty/

It needs a desktop browser with WebGL2 (Chrome or Edge is best) and plenty of memory (16 GB is comfortable). The whole
world is built on your machine as it loads, so the first load takes a while (a progress bar shows where it is).

Controls: drag to orbit, right-drag or shift-drag to pan, scroll to zoom, WASD to fly, 1-9 for viewpoints. The panel
holds the time of day, the reel and every setting.
